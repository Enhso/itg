# Synthetic example matches

This directory contains ten committed, fictional example matches generated by
`scripts/generate_examples.py`.

- `example-XX.jsonl` contains one synthetic event per line.
- `example-XX.ground_truth.json` contains the planted tactical shift answer key.
- The batch includes `high_press`, `possession_surge`, `direct_attack`, and
  `low_block` shifts across both teams.
- All teams, players, events, and outcomes are synthetic.

Regenerate the batch from the repository root with:

```bash
uv run python scripts/generate_examples.py
```

The generator is deterministic, so regeneration with the default arguments
should produce the same files.
